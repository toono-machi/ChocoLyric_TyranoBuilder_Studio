操作マニュアル はじめての方にもわかる使い方

歌詞・エンドロール・映像を、ゲームの音楽に合わせて制作するためのガイドです。

目次 CONTENTS
CHAPTER 01 / START HERE

まずはここから ─ 5ステップで完成

ChocoLyric Studio は、歌詞の字幕演出・流れるエンドロール・エンドロール用の画像／動画を、1曲の再生時刻に合わせて作れるブラウザアプリです。編集したものはティラノビルダー／ティラノスクリプトで使えるファイルとして書き出せます。

1音楽を読み込む左の「音声ファイルを選ぶ」から曲を選択します。
2演出を追加するSRT／TXTの歌詞、エンドロールカード、画像・動画のいずれかを追加します。
3タイミングと見た目を編集する中央で再生しながら、右パネルで時間・位置・色などを調整します。
4素材込みJSONを保存する後から編集できるよう、制作データをバックアップします。
5ゲーム用ZIPを書き出すZIPの data フォルダをゲームに統合して KS から呼び出します。
最初に知っておきたいこと

3つの制作モードは同じ音声を共有します。すべて使う必要はありません。「歌詞だけ」「エンドロールだけ」「映像だけ」でも制作できます。起動時には見本素材が入っていないため、使用したいファイルを読み込んでください。

CHAPTER 02 / WORKSPACE

画面の見方

① 画面上部

「使い方」「プロジェクトを開く」「素材込みJSON保存」「ティラノ用に書き出す」があります。

② 制作モードのタブ

「歌詞・SRT演出」「エンドロール」「エンドロール映像」を切り替えます。切り替えても同じプロジェクト内のデータを編集できます。

③ 左パネル

音声・字幕・画像／動画素材を読み込み、歌詞やカード、映像クリップを一覧管理します。

④ 中央パネル

実際の画面サイズで演出を確認し、音楽を再生したりタイムラインで時刻を移動したりします。

⑤ 右パネル

選択中の歌詞・エンドロール・映像の内容、タイミング、色やアニメーションを設定します。

項目を編集すると中央プレビューに反映されます。まずは左で対象を選択し、右で設定する流れを覚えるとスムーズです。

CHAPTER 03 / IMPORT

音声と歌詞を読み込む

音声ファイルの読み込み

  1. 左上の「音声ファイルを選ぶ」を押すか、その枠へ音声ファイルをドラッグします。
  2. MP3 / OGG / M4A / WAV などの音声ファイルを指定します。
  3. 中央の再生ボタンで曲が流れることを確認します。

歌詞の時間を正確に合わせたい場合は、先に音声を読み込むのがおすすめです。音声がなくても、仮のタイムラインで歌詞などの編集はできます。

SRTで歌詞を読み込む（時刻設定済みの場合）

「SRTを読み込む」を押すと、字幕に書かれた開始・終了時刻と歌詞本文が自動で取り込まれます。

1
00:00:03,000 --> 00:00:05,500
一行目の歌詞

2
00:00:05,500 --> 00:00:08,000
二行目の歌詞

上のように、字幕番号・表示時間・本文をまとめたテキストがSRTです。すでにタイミングを作ってある場合に向いています。

TXTで歌詞を読み込む（これから時刻を付ける場合）

  1. 1行ずつ歌詞を書いた .txt ファイルを用意します。
  2. 「歌詞TXTを読み込む」を押します。
  3. 左の「タイミング入力」に、まだ時刻を付けていない歌詞が並びます。
  4. 曲を流しながら、歌が始まる位置で各行をクリックします。
使い分けの目安

SRTは「時刻ごと取り込む」、TXTは「歌詞だけ取り込んで、あとからタイミングを付ける」形式です。

CHAPTER 04 / LYRIC TIMING

歌詞の表示タイミングを合わせる

TXTを再生しながら配置する

  1. 上部タブで「歌詞・SRT演出」を選びます。
  2. 左の「タイミング入力」を開き、中央で音声を再生します。
  3. 歌が始まる瞬間に歌詞行をクリックすると、その位置に歌詞が配置されます。Enter キーで次の未配置行を追加することもできます（文字入力欄にカーソルがないとき）。
  4. 間違えた場合は配置済みの行をもう一度押して解除し、やり直せます。

1フレーズずつ細かく編集する

  1. 左の「配置済みの歌詞」から変更したい行を選びます。
  2. 右上で本文を編集し、「開始（秒）」「終了（秒）」を数値で調整します。
  3. 再生位置を合わせて「現在位置 → 開始／終了」または中央の「IN／OUT を現在位置に」を押して、現在時刻を入力することもできます。
  4. 左の ＋ は歌詞追加、⧉ は複製、× は削除です。

開始は歌詞が現れる時間、終了は消える時間です。例えば 開始 3.00 秒／終了 5.50 秒 なら、その2.5秒間表示されます。

SRTを書き戻したいとき

左下の「SRT保存」で現在の歌詞とタイミングをSRTファイルに出力できます。ゲーム用ZIPとは別の機能です。

CHAPTER 05 / LYRIC STYLING

歌詞の見た目と動きを設定する

位置・文字・色

左の歌詞一覧で1行選ぶと、右側の「歌詞の演出を調整」が編集できます。横位置 X／縦位置 Y はスライダーのほか、中央のプレビューをクリック・ドラッグして位置を決められます。

フォント・太さ・サイズ・左／中央／右揃え・字間・文字色を調整できます。色見本のボタンからカラーサークルを開くか、HEXコードを直接指定してください。

フォントを追加する

「フォントファイルを追加」から TTF / OTF / WOFF / WOFF2 を読み込むと、フォント一覧で選べます。ゲーム用ZIPでは data/others/font/ へ同梱されます。「フォントのみZIPで保存」は素材の控えとして使えます。

装飾とアニメーション

  • 縁取り・影：縁取りのON/OFF、縁色と太さ、ドロップシャドウを設定。
  • 動きの種類：静止、タイプライター、ジャンプ、ウェーブ、スライド、ズームなどを選択。
  • 速度・大きさ：動きの速さと変化量をスライダーで調整。
  • フェード：フェードイン／アウトを個別にONにし、秒数を指定。

同じデザインをほかの行にも使う場合は、「この見た目・位置をすべての歌詞に適用」を押します。各歌詞の文章と表示時間はそのままで、見た目の設定を統一できます。

「プレビュー背景」は編集用です

プレビューの背景色や追加した背景画像は位置合わせのためのもので、ゲーム用演出には書き出されません。ゲーム本編の背景はティラノ側で用意してください。

CHAPTER 06 / END CREDITS

流れるエンドロールを作る

カードを追加・編集する

  1. 上部の「エンドロール」タブを選びます。
  2. 左の「追加する項目」で「原案」「シナリオ」「声優」「BGM」「主題歌」「任意」などを選択します。
  3. 右上の ＋ でカードを追加します。
  4. 左のカードを選択し、右の「選択中のカード」で見出しや名前を入力します。
  5. ⧉ で複製、× で削除できます。

通常の項目は1行に1名ずつ、改行で複数名を入力できます。「声優」はキャラ名と声優名を組み合わせる配役欄、「BGM」「主題歌」は作曲・編曲・歌唱などの専用項目を編集できます。入力欄内の薄い文字は記入例で、実際の出力には入りません。

流れる時間と方向を決める

右の「再生区間」で開始・終了秒を設定すると、その区間の中でクレジット全体が一定速度でスクロールします。「流れる方向」は下から上／上から下を選択できます。長いエンドロールは再生区間を広げると読みやすくなります。

横位置と文字揃え

「エンドロールの横位置」は画面幅の 0%（左）〜100%（右）で指定し、「左寄せ／中央／右寄せ」で位置と揃え方をまとめて設定できます。「文字の揃え方」は別々に指定することもできます。

「本文だけの横位置」は見出しを動かさずにクレジット名だけを左右へずらす機能です（−40%〜＋40%）。「本文位置をリセット」で0%に戻ります。

文字デザイン・背景パネル

  • 【 】で囲まれる見出しと、本文・クレジット名のフォント、サイズ、文字色、縁取りをそれぞれ設定できます。
  • 「見出しと本文の設定を一括調整」をONにすると、見出しの変更を本文にも反映できます。
  • 「角丸の背景パネルを表示する」をONにすると、パネル色と不透明度を調整できます。
CHAPTER 07 / VISUAL TIMELINE

エンドロール用の画像・動画を配置する

  1. 上部の「エンドロール映像」タブを開きます。
  2. 左の「画像・動画を読み込む」で PNG / JPG / WEBP / GIF / MP4 / WEBM などを複数読み込みます。
  3. 中央のタイムラインをクリックして、画像を表示したい時刻へ移動します。
  4. 左の素材一覧で ＋ を押すと、その時刻に映像クリップが追加されます。
  5. 左の「映像タイムライン」からクリップを選び、右の開始・終了秒を調整します。

切り替えと表示方法

  • 次の素材への切り替えまで表示：次のクリップが始まるまで現在の素材を保持します。最後の素材は終了時刻も確認してください。
  • クロスフェードで切り替える：ONなら重なりながら切り替え、OFFなら瞬時に切り替えます。「切り替え時間」でフェードの長さを指定できます。
  • 画面への配置：「画面を埋める」は中央トリミング、「画像全体を表示」は余白を許して全体を表示します。
  • 動画をループ再生する：動画クリップを選んだときだけ表示。ONは表示区間中に反復、OFFは終了後に最後のフレームを保持します。

素材一覧の × は素材の削除、クリップ一覧の ⧉ はクリップの複製です。動画内の音声はミュートされ、読み込んだ楽曲の再生時刻に同期します。

歌詞を映像に重ねたいとき

プレビューの「歌詞も重ねる」をONにしてください。ゲームでの前面表示順は 歌詞 → エンドロール → 映像 です。

CHAPTER 08 / PREVIEW & KEYS

プレビューと再生操作

ゲーム画面のサイズを合わせる

中央上部「ゲーム画面」から、1920×1080 / 1280×720 / 4:3などを選択できます。「カスタムサイズ」では横幅と高さを指定できます。ゲーム本体の画面解像度と合わせてください。サイズの切り替えに応じて歌詞の位置やサイズも再計算されます。

再生・停止位置の操作

中央の ▶ は再生／一時停止です。「−1s」「＋1s」は1秒移動、「‹」「›」は0.1秒移動です。タイムラインの空き部分をクリック・ドラッグして目的の時刻へ移動できます。「ループ」はプレビューの繰り返し再生です。

キー動作
Space再生／一時停止
← / →0.1秒戻る／進む
Shift＋← / →1秒戻る／進む
EnterTXTから次の未配置歌詞を配置
Ctrl＋S素材込みJSON保存

※ 文字入力欄やプルダウンで入力している間は、再生などのショートカットは働きません。マニュアル表示中もショートカットは無効です。

歌詞モードの「選択中を常時表示」は、指定した表示時間外でも選択中の歌詞を確認するための編集補助です。

CHAPTER 09 / SAVE & LOAD

作業データの保存と復元

編集を続けたい場合はJSONを保存

  1. 画面右上の「素材込みJSON保存」を押します。
  2. chocolyric_project_full.json がダウンロードされます。
  3. 後日、右上の「プロジェクトを開く」から保存したJSONを読み込めば、編集状態を復元できます。

現行形式のJSONには歌詞・タイミング・設定だけでなく、読み込んだ音声、画像、動画、追加フォント、プレビュー背景のデータも含まれます。通常は同じファイルを読み込み直す必要はありません。

JSONとゲーム用ZIPは役割が違います

JSON：編集を再開するための保存データ。
ティラノ用ZIP：ゲームに組み込むためのKSファイルと素材。
作業を失わないため、書き出す前にJSONも保存することをおすすめします。

大きな動画などを含むJSONは、Base64化により素材の合計サイズより約33%大きくなることがあります。容量やブラウザのメモリに注意してください。古い形式のJSONでは素材を再選択する必要がある場合があります。

CHAPTER 10 / EXPORT

ゲーム用ZIPを書き出す

  1. 歌詞・エンドロール・映像のうち、少なくとも1つを用意します。
  2. 画面右上の「ティラノ用に書き出す」を押します。
  3. 使用するゲーム内の音声ファイル名を確認します。読み込んだ音声があれば元のファイル名が使われます。
  4. 音声もZIPへ入れる場合は「読み込んだ音声もZIPに含める」をONにします。
  5. 「ZIPをダウンロード」を押します。

ZIPに入るもの

data/
├─ scenario/　… 再生・停止のKSファイル
├─ bgm/　　　 … 音声（同梱した場合）
├─ fgimage/　　… 使用する画像
├─ video/　　　… 使用する動画
└─ others/font/ … 追加フォント

README_導入手順.txt　… ゲームへの導入方法

歌詞SRT・エンドロールや映像のタイムライン情報も、作成した内容に応じて付属します。使っていない制作モードの専用ファイルは生成されない場合があります。KSには必要な描画処理が含まれており、別途JSファイルを作る必要はありません。

音声を同梱しない場合

同梱チェックをOFFにしたときは、指定した音声ファイルを自分でゲームプロジェクトの data/bgm/ に配置してください。読み込んだ音声がないまま同梱ONで書き出すことはできません。

CHAPTER 11 / TYRANOBUILDER

ティラノビルダーへの導入方法

  1. ゲーム用ZIPを解凍します。
  2. ZIP内の data フォルダの内容を、制作中ゲームの data フォルダに統合します。既存のゲームのフォルダを丸ごと削除・置き換えないでください。
  3. ティラノビルダーで、演出を開始したい場面に「ティラノスクリプト」コンポーネントを置き、次のKSを書きます。

ゲーム開始時の初期化（任意）

[call storage="choco_setup.ks"]

CHAPTER 12 / TROUBLESHOOTING

よくある困りごと

Q. 音が出ない／ゲーム上で再生できない

音声ファイルが data/bgm/ にあり、ZIP書き出し時のファイル名と一致するか確認してください。ブラウザや実行環境によっては、最初のクリック操作があるまで音声が再生できない場合があります。

Q. 歌詞が表示されない

歌詞が配置されているか、各行の開始・終了秒が合っているかを確認してください。ゲームとプレビューの画面解像度も合わせます。「選択中を常時表示」はプレビュー用の補助設定です。

Q. SRT／TXTを読み込んだのに時刻が合わない

SRTの時間表記、終了時刻が開始時刻より後かどうかを確認します。TXTは自動で時刻を割り当てないため、「タイミング入力」から配置してください。

Q. フォントが変わらない／ZIPを書き出せない

右のフォント選択が読み込んだものになっているか確認してください。古いJSONで「再読み込みが必要」と表示された場合は、元のフォントファイルを再登録してください。ゲームへのフォント同梱の許諾も確認してください。

Q. 画像・動画が表示されない

素材を読み込んだだけでなく、時刻を決めて映像クリップを追加したか確認してください。クリップの表示区間、配置方法、「次の素材への切り替えまで表示」も確認します。動画の対応コーデックはゲーム実行環境に依存します。

Q. 音楽が二重に鳴る

ChocoLyricのKSとは別に、同じ音楽を [playbgm] などで再生していないか確認してください。ChocoLyric側で再生する場合、同じ曲を別途流す必要はありません。

Q. 保存したJSONが大きい／開けない

動画などの素材も保存するためサイズが大きくなります。ブラウザの空きメモリを確保してください。旧形式のJSONでは素材の再選択が必要になる場合があります。制作中はJSONを別の場所にも控えておくと安全です。

Q. プレビューの背景がゲームで出てこない

「プレビュー背景」は編集補助です。ゲーム画面の背景はティラノビルダー側で別に設定してください。
