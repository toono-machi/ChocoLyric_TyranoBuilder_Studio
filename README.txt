ChocoLyric Studio v2.9
ティラノビルダー 歌詞 & エンドロール演出制作ブラウザアプリ
====================================================

【起動】
「index.html」をGoogle Chrome / Microsoft Edgeで開いてください。
ローカルで動作し、インターネット接続は不要です。
画面はチョコレート×バニラ色で、1920×1080などティラノビルダーの解像度に対応しています。

【操作マニュアル】
画面右上の「? 使い方」から、13章の詳細マニュアルを開けます。
初回操作、各モード、書き出し、ティラノビルダーへの導入、トラブル対応まで掲載しています。
左の目次から章を移動でき、上部の検索欄で「SRT」「ZIP」「クロスフェード」などを検索できます。
右上の「×」、または本文末尾の「マニュアルを閉じる」で閉じられます。

【歌詞・SRT演出タブ】
・音声（MP3 / WAV / OGGなど）、歌詞SRT / TXTを読み込みます。
・タイミング入力、位置調整、縁取り、文字色と縁色、フォント、フェード、アニメーションに対応します。
・ユーザーが読み込んだフォント（TTF / OTF / WOFF / WOFF2）はゲーム書き出しZIPに同梱されます。
・起動時は歌詞・映像・音声・フォントがすべて空です。利用する素材を読み込んでください。

【エンドロール映像タブ】
1. 共通の音声ファイルを読み込みます。
2. 画像（PNG/JPG/WEBPなど）または動画（MP4/WebMなど）を複数読み込みます。
3. 音声を再生・シークし、表示したい時刻に素材一覧の「＋」を押して挿入します。
4. タイムラインのクリップを選択して開始・終了時刻を微調整します。
5. 「クロスフェードで切り替える」をONにすると切り替え時刻から指定秒数で次の素材に移行します。
   OFFにすると一瞬で切り替わります。新しいクリップの設定を変更してください。
6. 「次の素材への切り替えまで表示」をONにすると次の開始時刻まで自動保持します。
   最後の素材は終了時刻で表示が終わります。必要に応じて最後の終了時刻を設定してください。
7. 動画を選択した場合にだけ「動画をループ再生する」のチェックが表示されます。
   ON：表示区間の間繰り返し再生。OFF：動画終了後は最終フレームを維持します。
   動画の再生とループは選択した音声の時刻に同期します。
8. プレビューの「歌詞も重ねる」で、既存の歌詞表示を重ねて確認できます。
   動画内の音声はミュートして、共通の楽曲の時計に同期します。

【ゲーム用ZIP】
画面右上の「ティラノ用に書き出す」を押してZIPをダウンロードします。
読み込んだ画像・動画・フォント・音声の元ファイル（変換なし）を元のファイル名でZIPへ含めます。
同じ名前の画像・動画がある場合は素材別のサブフォルダに分け、ファイル名自体は変更しません。

ゲームZIPに含まれるファイル例：
  data/scenario/choco_setup.ks     最初に1回読み込む初期化処理（任意）
  data/scenario/choco_start.ks     歌詞と映像の開始（片方のみの場合も生成）
  data/scenario/choco_quick_test.ks 15秒間の動作確認用
  data/scenario/choco_stop.ks      歌詞と映像の一括停止
  data/scenario/lyrics_show.ks     歌詞単独で開始（歌詞がある場合）
  data/scenario/lyrics_stop.ks     歌詞単独で停止（歌詞がある場合）
  data/scenario/credits_show.ks    エンドロール単独で開始（映像がある場合）
  data/scenario/credits_stop.ks    エンドロール単独で停止（映像がある場合）
  data/fgimage/choco_credits/     読み込んだ画像ファイル
  data/video/choco_credits/       読み込んだ動画ファイル
  data/others/font/              読み込んだ追加フォントファイル
  data/bgm/                      読み込んだ音声（同梱チェックONの場合）
  README_導入手順.txt             生成した内容に合わせた手順書

ゲームプロジェクトにdataフォルダを統合したら、ティラノビルダーの
「ティラノスクリプト」コンポーネントに以下を記述できます。

【KS記述例】
ゲーム冒頭で初期化したい場合（任意）：
[call storage="choco_setup.ks"]

再生したい場面：
[call storage="choco_start.ks"]

★音声を停止したい【別の場面】：
[call storage="choco_stop.ks"]

※ [call]は再生終了まで待ちません。開始と停止を続けて記述すると即時停止します。
※ choco_start.ks は「歌詞のみ」「映像のみ」でも出力されるようになりました。

【動作確認：最初はこれだけをシナリオに記述】
[call storage="choco_quick_test.ks"]

choco_quick_test.ks には初期化・開始・15秒待機・停止が含まれています。
動作しない場合はZIPの data/bgm/ に音声があり、ゲームプロジェクトのdata/bgm/と一致するか確認してください。

【歌詞を先に始め、途中からエンドロール映像を表示】
[call storage="lyrics_show.ks"]
; 続けて、同じKS内や後のKSで
[call storage="credits_show.ks"]

【停止】
[call storage="choco_stop.ks"]

歌詞とエンドロールは1つの音声を共有して再生します。
表示順は通常の背景・キャラ画像 < エンドロール画像・動画 < 歌詞です。
独立したJSファイルをゲーム用ZIPには生成しません。KS内にJavaScriptを組み込んでいます。

【注意】
・音声を再生する位置と同じ時計を使用するため、別途[playbgm]で同曲を流さないでください。
・[call]は音声終了まで処理を待ちません。
・動画の対応形式は環境（Chromium/NW.js）に依存します。MP4(H.264)やWebMを推奨します。
・ゲーム上での実機確認は必要です。ゲームの画面解像度とアプリ設定を揃えてください。
・「素材込みJSON保存」で音声・画像・動画・フォント・プレビュー背景をすべてプロジェクトJSONへ埋め込んで保存します。
  次回「プロジェクトを開く」から読み込むと素材も自動復元されます（同一ファイルを再選択する必要はありません）。
・動画などの素材はBase64形式になるため、JSONの容量が元の合計ファイルサイズの約1.33倍以上になります。
  大容量プロジェクトは保存・読み込み時にPCのメモリを多く使用します。
・v2.3以前のJSONは素材が含まれないため、以前のJSONを読み込んだ場合のみ素材を再選択してください。
・大型動画のZIP作成にはブラウザの空きメモリを必要とします。
・素材やフォントのゲーム同梱・配布は利用規約をご確認ください。

【制作元について】
ChocoLyric Studioはティラノビルダー／ティラノスクリプトの公式製品ではない、
独立した非公式のゲーム制作補助アプリです。
ティラノ公式開発者の連絡先（メール・SNS）は、このアプリのサポート窓口ではありません。
混同を避けるため本アプリの連絡先としては掲載していません。

【v2.7 追加・修正】
・＋／×などのアイコンボタンを中央揃えに修正しました。
・新規の歌詞とクレジット入力欄は未入力。グレーの記入例（placeholder）は入力時に消え、保存・表示には含まれません。
・エンドロールの見出し【項目】と本文のフォント、サイズ、文字色、縁取り太さ・色を個別設定できます。
・「見出しと本文の設定を一括調整」で見出しの変更を本文に連動できます。
・背景の角丸パネルは表示のON/OFFに対応。カラーサークルで色指定、不透明度も調整できます。
・エンドロールの文字・背景設定は素材込みJSONへ保存され、ティラノ用KSにも同じ描画処理で出力されます。
・追加フォントは歌詞・エンドロールどちらからも読み込め、エンドロールの見出し・本文のフォント選択で使用できます。
・v2.6のJSONプロジェクトも読み込み可能で、従来の見た目を初期値として引き継ぎます。

【v2.8 追加・修正】
・エンドロール全体の横位置を0%（左端）～100%（右端）のスライダーで調整可能。
・文字揃えを左揃え／中央揃え／右揃えから選択可能。
・「左寄せ」「中央」「右寄せ」ボタンで横位置と文字揃えを一括設定。
・JSONプロジェクトへの保存・復元とゲーム用KS書き出しに反映。
・v2.7以前のJSONは中央（50%）、中央揃えとして読み込むため互換性を保持。

【v2.9 追加・修正】
・エンドロール本文専用の横位置スライダーを追加しました（画面幅の -40% ～ +40%）。
・見出し【 】とエンドロール全体の横位置はそのまま、本文・クレジット名だけを左右へ移動します。
・左寄せ／中央／右寄せのどの文字揃えでも独立調整できます。
・「本文位置をリセット」で横位置の追加調整だけを0%に戻せます。
・角丸背景をONにした場合、移動した本文が背景からはみ出さないようパネル幅が広がります。
・プレビュー・素材込みJSON保存/復元・ティラノ用KS出力の全てに本文位置を反映します。
・v2.8以前のJSONに本文位置が存在しない場合は 0% として読み込み、旧データの表示を維持します。
